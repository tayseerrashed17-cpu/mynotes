# COMP1238 - My Course Notes

## Week 1 - History

- One writing system can be used to write several different languages.
- Movable type allowed individual characters to be rearranged to print different texts.

## Week 2 - Bits and Bytes

- ⁠Binary uses base 2, while hexadecimal uses base 16 with digits 0–9 and letters A–F.
- ASCII assigns numbers to characters, such as 65 for the uppercase letter A.


## Week 3
⁠- JSON objects contain key-value pairs inside curly braces, while arrays use square brackets.
- ⁠Escaping allows special characters to be treated as ordinary text instead of formatting or instructions.

## Week 4
- Search and replace helps us find text and change repeated words or phrases.
- ⁠Regular expressions describe patterns that can be used to search for matching text.


## Week 5
- The cat command prints file contents, while less lets us scroll through a file.
- A pipe | sends one command's output to another command as input.
